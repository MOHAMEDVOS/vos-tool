# Screenshots for the main README

Each feature gets its own folder below. Open the `NOTES.md` inside a folder
to see what to capture, then save your screenshot in that same folder as
`screenshot.png` — same name every time, so there's nothing to rename.

| Folder | Page in the app |
|---|---|
| `dashboard/` | Dashboard → Agent Audit tab |
| `call-auditing/` | Audit page |
| `rebuttal-detection/` | Call Review page |
| `late-hello-releasing/` | Call Review page or Actions page |
| `scoring/` | Scoring page |
| `user-management/` | Users page → Create mode (bulk dialer user creation) |
| `campaign-reports/` | Dashboard → Campaign tab, or the generated Sheet/Doc |
| `tl-actions/` | TL Actions page |
| `settings-sharing/` | Settings page |

Capture at a normal desktop width (1440px+ wide is plenty) with the sidebar
visible, logged in as a user who can see the feature (Owner for owner-only
pages). Blur or swap out real customer names/phone numbers before saving —
use a demo account or a quiet day's data.

Once `screenshot.png` exists inside a folder, it shows up in the main
[README.md](../README.md) automatically — nothing else needs to change.
