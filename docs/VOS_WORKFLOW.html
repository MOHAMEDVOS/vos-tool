VOS Workflow

The active VOS runtime is React on port 3000 with FastAPI on port 8000.

Runtime Flow

  1. Users open the React webapp.
  2. The webapp authenticates with the FastAPI backend using localStorage JWTs.
  3. Audit uploads, dashboard actions, ReadyMode, phrase management, settings, quota, sharing, campaign reports, and system sessions all call backend API routes.
  4. Background audio processing runs through backend jobs and Celery workers.

Docker Services

  • webapp: React static build served by nginx.
  • backend: FastAPI and business services.
  • postgres: application database.
  • redis: job queue broker and result backend.
