ReadyMode phone issue

Agents stuck on "Preparing Connection", can't make or receive calls. Dialer: resva7. Agent tested: RES-1245. Date: 18 Jun 2026.

What's happening

The phone connects to ReadyMode fine, but the voice part never logs in. Every time it tries to register (SIP REGISTER), ReadyMode's phone server answers 401 Unauthorized, even though the phone sends the correct password. So it keeps retrying and never turns "Connected".

It tried 48 times. 48 got rejected. 0 succeeded.

Why it's on ReadyMode's side, not ours

We tested it ourselves from a different computer and network. Same result. The rejection has nothing to do with the agent's PC, browser, internet, firewall or VPN, those all work. The phone server is simply refusing the SIP password, and that password lives on ReadyMode's side. The agent can't change it.

What we checked

Working: login, ReadyMode app, internet/firewall (STUN passes), microphone, browser, and the app data channel.
Failing: only the SIP voice login (REGISTER gets 401). That's the one thing stopping the phone.

What to ask ReadyMode support

"Our agents' phones are stuck on 'Preparing Connection'. We checked the traffic and your phone server is rejecting the SIP password (REGISTER keeps returning 401 Unauthorized, never 200 OK), so the softphone never registers. Please reset / re-provision the SIP password for the affected agents. Did something change on the PBX about a week ago?"

If they need details: tenant resva7, PBX Asterisk certified-20.7-cert4, host 1-8-phx.xensub.net, endpoint 28850-20026 (RES-1245).
