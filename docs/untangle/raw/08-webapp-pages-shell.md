## Needless Links

- `CallReviewPage.tsx:11` imports `AgentDeductionsTable` and `AgentDeductionRow` from `@/pages/ActionsPage` — one page reaching into another page's internals as if it were a shared component module. Any refactor of `ActionsPage.tsx` for Actions-specific reasons (it's the file that owns delete-agent-audits, filters, etc.) risks breaking `CallReviewPage.tsx`, which has nothing to do with that workflow.
- `AgentDeductionsTable`'s `onDeleteAgent`/`deletingAgent`/`deletableAgents` props (`ActionsPage.tsx:41-48`, consumed at `ActionsPage.tsx:72,194-212`) exist only for `ActionsPage`'s own delete-agent workflow. `CallReviewPage.tsx:244` renders the same component without them — the "shared" table isn't really general, it's `ActionsPage`'s table with caller-specific knobs bolted on.
- `Sidebar.tsx:12` imports `inferPhase` from `@/hooks/useAuditStream` — a hook named after, and shaped around, one feature's (Audit) streaming internals — directly into the always-mounted layout shell. The shell (which should be the most stable code in the app) now changes whenever the audit feature's progress/phase model changes; the drifted `Math.min` clamp above is a direct consequence.
- `UsersPage.tsx` never uses the shared `@/api/client` (`api`/`authHeaders()`, used elsewhere e.g. `CallReviewPage.tsx:7,329,443`) and instead reads `token` from `useAuthStore` (`UsersPage.tsx:248`) and hand-writes `Authorization: Bearer ${token}` at six separate `fetch` call sites (364-397, 434-467, 502-543, 566-608, 658-709, 732-774). A change to the auth scheme (refresh tokens, header rename) means fixing six call sites here instead of one shared function.
- `CallReviewPage.tsx:433-459` (`AuthenticatedAudio`) hand-rolls `fetch` + manual blob/object-URL handling + its own error parsing, instead of extending the `api` client this same file already uses for JSON (`api.get` at `CallReviewPage.tsx:329`) — because that shared client has no blob-response support, every caller that needs an authenticated binary fetch has to reimplement this itself.
- `AuditPage.tsx:66-252` (`MultiSelectDropdown`) is a full general-purpose searchable multi-select (outside-click-to-close, fixed positioning via `getBoundingClientRect`, select-all) built as a private, unexported function inside the Audit page, duplicating infrastructure that belongs next to the `CustomSelect`/`CustomDatePicker` components this same file already imports from `components/ui/`. It's unreachable from any other page without copy-pasting it again.
- `ActionsPage.tsx:60-72` (`AgentDeductionsTable`'s `headers` array) changes shape — gains a `Delete` column — purely because `ActionsPage` passed `onDeleteAgent`; the "general" table's column list is really dictated by one specific caller's workflow.
